## 1. 待開發任務 (Todo List)

### [P0] 任務一：基礎環境建置與會員認證模組
- **狀態**：`[x] Done`
- **相依關係**：無
- **驗收條件**：
  - [x] 初始化後端 FastAPI，配置 SQLite 資料庫連線，並能於本地啟動。
  - [x] 初始化前端 React 專案，架設基礎 RWD 佈局與路由。
  - [x] 實作會員註冊與登入 API，密碼使用 Bcrypt 雜湊，成功時回傳 JWT Token。
  - [x] 前端實作註冊與登入頁面，區分「消費者」、「商家」、「外送員」註冊入口。

### [P0] 任務二：商家端商品與接單管理
- **狀態**：`[x] Done`
- **相依關係**：任務一完成
- **驗收條件**：
  - [x] 商家登入後可管理菜單商品（新增商品、修改名稱/價格、刪除商品、切換供應狀態）。
  - [x] 商家可取得該店的訂單清單。
  - [x] 商家可點擊「接單」（狀態由 `pending` 變為 `preparing`）。
  - [x] 商家可點擊「餐點完成」（狀態由 `preparing` 變為 `ready`）。

### [P0] 任務三：消費者端店家瀏覽與點餐結帳
- **狀態**：`[x] Done`
- **相依關係**：任務一、任務二完成
- **驗收條件**：
  - [x] 消費者登入後可瀏覽所有合作商家列表。
  - [x] 消費者點擊某商家可瀏覽其商品菜單（商品大於0且處於供應狀態）。
  - [x] 實作購物車機制，可增減數量、防範跨店點餐（切換店家時清空）。
  - [x] 點餐結帳：包含購物車小計，固定加計 39 元外送費，不設起送價門檻，僅支援 COD (貨到付款)。
  - [x] 送出訂單後，自動進入「訂單追蹤頁面」，並以 5 個階段的進度條顯示狀態。
  - [x] 消費者可看見並即時追蹤其目前訂單的最新狀態。

### [P0] 任務四：外送員大廳搶單與配送結案
- **狀態**：`[x] Done`
- **相依關係**：任務一、任務三完成
- **驗收條件**：
  - [x] 外送員登入後可瀏覽訂單大廳（列表僅呈現狀態為 `ready` 且尚未有外送員接單的訂單）。
  - [x] 外送員點擊「搶單」，系統綁定 `rider_id` 並更新訂單狀態為 `delivering`；且後端實作 with_for_update 交易寫鎖防止重複搶單，後搶者回傳 409 衝突。
  - [x] 外送員可點擊「確認送達並收款」（收取現金後結案，狀態更新為 `delivered`）。
